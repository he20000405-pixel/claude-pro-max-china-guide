# Claude Pro and Max Subscription Guide for Users in China

This is ChongGrok's independent knowledge base for Claude Pro, Max 5x and Max 20x plan selection, account safety, payment troubleshooting and Claude Code access. The current merchant service is limited to a personal monthly Pro subscription on the customer's own account, opened through assisted iOS in-app purchase. It does not include Max, team seats or API credits.

[View the current Claude service page](https://chonggrok.com/claude)

> ChongGrok is an independent third-party subscription assistance service. It is not affiliated with, authorized by or officially partnered with Anthropic. Plan availability, pricing, usage limits and regional access are determined by Anthropic.

## Start with the symptom you see

| Current situation | First check | Stop condition |
| --- | --- | --- |
| You have not subscribed and do not know which plan to choose | Record where Free or Pro actually blocks your work before comparing plans | Do not upgrade if the current plan completes your regular tasks |
| A card payment failed | Save the exact error, time and billing channel before troubleshooting | Do not retry if a charge, pending transaction or receipt exists |
| You paid but Claude still shows Free | Match the receipt email, current login and `Settings > Billing` | Do not create a second subscription while the first order is unresolved |
| Claude Code does not use the membership | Confirm the web plan is active, then check the account used by the terminal | Stop if Claude Code is using API-key billing instead of the subscription |

Taxes and regional prices may differ. This table explains official plans, not ChongGrok's available products. ChongGrok does not offer Max 5x or Max 20x; use [Claude's official plan page](https://claude.com/pricing) for Max purchase and management options.

## Personal monthly Pro service flow

1. Sign in to the Claude account that should receive the subscription.
2. Check `Settings > Billing` for an active or pending subscription.
3. Visit [chonggrok.com/claude](https://chonggrok.com/claude) to confirm the personal monthly Pro service, supported-region eligibility, required data and after-sales conditions.
4. Pay through the confirmed order path and provide only the account information needed for that order. If a User ID is requested, confirm its purpose and account ownership first.
5. The service opens Pro through assisted iOS in-app purchase.
6. Check Pro status, the subscription period and the delivery result in the original Claude account's `Settings > Billing`.

No Claude password, email password, verification code or recovery code is requested; do not send a full session token. A Claude User ID is an account identifier. Submit it only if the current order requires it and its purpose has been explained. Payment or iOS in-app purchase does not change regional eligibility or identity-verification requirements.

The process is complete only when the target account shows the expected plan in `Settings > Billing`, the login email matches the intended account and Claude Code uses the same subscription identity. A payment message or support chat alone does not prove that the paid plan is active on that account.
